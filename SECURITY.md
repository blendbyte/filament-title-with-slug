# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| 2.x     | Security and severe bug fixes only |
| 1.x     | Security and severe bug fixes only |

Please upgrade to 3.x when you can. See the [Upgrading](README.md#upgrading) section in the README.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Prefer GitHub's private vulnerability reporting:

https://github.com/blendbyte/filament-title-with-slug/security/advisories/new

If that is not available, email [hello@blendbyte.com](mailto:hello@blendbyte.com) with a description of the issue and steps to reproduce.

We will acknowledge the report and work on a fix. Please give us a reasonable window to patch and release before any public disclosure.
